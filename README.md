# 🚢 Titanic Survival Prediction – Final Data Science Project

## 📌 Project Overview

This is my **Final Data Science Project** based on the Titanic dataset. The project covers an end-to-end Data Science workflow, from data analysis and visualization to Machine Learning model building and evaluation.

## 🎯 Objective

The main objective of this project is to analyze the Titanic passenger dataset and build a Machine Learning model to predict whether a passenger survived or not.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## 🔍 Project Workflow

* Data Collection
* Data Exploration
* Data Cleaning
* Handling Missing Values
* Exploratory Data Analysis (EDA)
* Data Visualization
* Feature Engineering
* Machine Learning
* Model Training
* Model Evaluation
* Survival Prediction

## 📊 Exploratory Data Analysis

The project analyzes:

* Survival distribution
* Gender-wise survival
* Passenger class-wise survival
* Age distribution
* Fare distribution
* Correlation between numerical features

## 🤖 Machine Learning

A **Logistic Regression** model is used to predict passenger survival.

### Model Evaluation

The model is evaluated using:

* Accuracy Score
* Classification Report
* Confusion Matrix

## 📈 Results

The project successfully demonstrates how passenger characteristics such as **gender, passenger class, age, and fare** can be used as features for survival prediction.
